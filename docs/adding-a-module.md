# Adding a Module — end-to-end walkthrough

This guide adds a new `Products` module alongside `Todos`. The `Todos` module is
the reference; copying it is the fastest start. Every path is relative to the
repository root.

> **TL;DR** — create a project referencing `BuildingBlocks`, fill in the vertical
> slice, generate migrations into the module, implement `IModule`, and add one
> line to `Program.cs`.

## 1. Create the project

```
src/Modules/Products/Products.csproj
```

Copy `src/Modules/Todos/Todos.csproj` verbatim — the package set is identical
(EF Core + Npgsql + naming conventions, FluentValidation, PediatR, Mapperly,
and `Microsoft.EntityFrameworkCore.Design` for migrations). It should reference
only `BuildingBlocks`:

```xml
<ItemGroup>
  <ProjectReference Include="..\..\BuildingBlocks\BuildingBlocks.csproj" />
</ItemGroup>
```

Add the project to the solution and to the host's references:

```bash
dotnet sln ReadyTemplate.slnx add src/Modules/Products/Products.csproj
dotnet add src/Bootstrapper/Api/Api.csproj reference src/Modules/Products/Products.csproj
```

Create a `Usings.cs` with the module's global usings (copy the Todos one and
swap `Todos.*` for `Products.*`).

## 2. Domain

```csharp
// src/Modules/Products/Domain/ProductEntity.cs
namespace Products.Domain;

public class ProductEntity : BaseEntity
{
    public string Name { get; set; } = string.Empty;
    public decimal Price { get; set; }
}
```

Inheriting `BaseEntity` gives you Id (GUID v7), timestamps, soft delete, and
audit logging for free.

## 3. Application

Define the module's data contract, feature class, commands, views, validators,
and mapper — mirroring `Todos`:

```csharp
// Application/IProductsDbContext.cs
namespace Products.Application;

public interface IProductsDbContext
{
    DbSet<ProductEntity> Products { get; }
    Task<int> SaveChangesAsync(CancellationToken cancellationToken = default);
}
```

```csharp
// Application/ProductFeatures.cs
namespace Products.Application;

public sealed class ProductFeatures(IProductsDbContext dbContext)
{
    [Query]
    public async Task<TableResponse<ProductView>> GetAllAsync(TableOptions options, CancellationToken ct = default)
    { /* … same shape as TodoFeatures.GetAllAsync … */ }

    [Command]
    public async Task<ProductView> CreateAsync(CreateProductCommand command, CancellationToken ct = default)
    { /* … */ }
}
```

- `Commands/` — records implementing `ICommand<T>` (e.g.
  `record CreateProductCommand(CreateProductView View) : ICommand<ProductView>;`).
- `Views/` — request/response DTOs.
- `Validators/` — `AbstractValidator<>`; discovered and run automatically.
- `Mapping/` — a Mapperly `[Mapper]` static partial class.

See [CQRS & Validation](cqrs-validation.md) for the conventions.

## 4. Infrastructure (schema + migrations)

```csharp
// Infrastructure/ProductsDbContext.cs
namespace Products.Infrastructure;

public sealed class ProductsDbContext(DbContextOptions<ProductsDbContext> options)
    : ModuleDbContext(options), IProductsDbContext
{
    public const string Schema = "products";
    protected override string ModuleSchema => Schema;

    public DbSet<ProductEntity> Products => Set<ProductEntity>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder);
        modelBuilder.ApplyConfigurationsFromAssembly(typeof(ProductsDbContext).Assembly);
    }
}
```

Add EF configurations under `Infrastructure/Configurations/` and a design-time
factory (copy `TodosDbContextFactory`, swap the type and schema) so `dotnet ef`
can build the context without booting the host.

Generate the module's first migration **into the module project**:

```bash
dotnet ef migrations add InitialCreate \
  --project src/Modules/Products/Products.csproj \
  --startup-project src/Bootstrapper/Api/Api.csproj \
  --context ProductsDbContext \
  --output-dir Infrastructure/Migrations
```

The migration lands in the `products` schema with its own
`products.__ef_migrations_history` table. See [Persistence](persistence.md).

## 5. Endpoints

```csharp
// Endpoints/ProductEndpoints.cs
namespace Products.Endpoints;

internal static class ProductEndpoints
{
    public static IEndpointRouteBuilder MapProductEndpoints(this IEndpointRouteBuilder app)
    {
        var group = app.MapGroup("/api/products").WithTags("Products");

        group.MapGet("/", ([AsParameters] TableOptions options, ISender sender, CancellationToken ct)
            => sender.ProductFeatures().GetAllAsync(options, ct));

        group.MapPost("/", (CreateProductView view, ISender sender, CancellationToken ct)
            => sender.Send(new CreateProductCommand(view), ct));

        return group;
    }
}
```

`sender.ProductFeatures()` is generated by PediatR from your `[Query]`/`[Command]`
methods.

## 6. The module class

```csharp
// ProductsModule.cs
namespace Products;

public sealed class ProductsModule : IModule
{
    public Assembly Assembly => typeof(ProductsModule).Assembly;

    public IServiceCollection RegisterModule(IServiceCollection services, IConfiguration configuration)
    {
        services.AddDbContext<ProductsDbContext>((sp, options) => options
            .UseNpgsql(
                configuration.GetConnectionString("Default"),
                npgsql => npgsql.MigrationsHistoryTable("__ef_migrations_history", ProductsDbContext.Schema))
            .UseSnakeCaseNamingConvention()
            .AddModuleInterceptors(sp));

        services.AddScoped<IProductsDbContext>(sp => sp.GetRequiredService<ProductsDbContext>());
        services.AddScoped<ProductFeatures>();

        services.AddHealthChecks()
            .AddDbContextCheck<ProductsDbContext>("products-db", tags: ["ready"]);

        return services;
    }

    public IEndpointRouteBuilder MapEndpoints(IEndpointRouteBuilder endpoints)
    {
        endpoints.MapProductEndpoints();
        return endpoints;
    }

    public async Task InitializeAsync(IServiceProvider services)
    {
        using var scope = services.CreateScope();
        var db = scope.ServiceProvider.GetRequiredService<ProductsDbContext>();
        await db.Database.MigrateAsync();
    }
}
```

## 7. Register it with the host — the one-line change

```csharp
// src/Bootstrapper/Api/Program.cs
IModule[] modules = [new TodosModule(), new ProductsModule()];
```

That's it. The host scans the new module's assembly for validators and mediator
handlers automatically — no other host change is needed.

## 8. Verify

```bash
dotnet build ReadyTemplate.slnx -warnaserror
dotnet test
dotnet run --project src/Bootstrapper/Api
# → GET/POST http://localhost:5246/api/products
```

## Checklist

- [ ] Project created, references **only** `BuildingBlocks`
- [ ] Added to `ReadyTemplate.slnx` and referenced by `Api.csproj`
- [ ] Entity inherits `BaseEntity`
- [ ] `I<Module>DbContext` + `<Module>DbContext : ModuleDbContext` with a unique `Schema`
- [ ] Design-time factory present
- [ ] Migration generated into the module
- [ ] `IModule` implemented (register + map + migrate)
- [ ] One line added to `Program.cs`
- [ ] `dotnet build -warnaserror` and `dotnet test` are green
